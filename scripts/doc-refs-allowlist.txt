# 文档引用的**显式豁免清单**。
#
# 判据要求：文档里每个解析不到的引用要么修好，要么在此登记并写明所有者与理由。
# 未登记的一律失败——这样"文档里多了一条指向不存在路径的引用"不可能悄悄发生。
#
# 反向也强制：一条不再命中的豁免会让门禁失败。引用修好了、或文档删了，
# 豁免就该跟着删——留着的例外没人看，只会掩盖下一次真实缺陷。
#
# 格式：<文档路径>:<引用的文件部分>  # <所有者> — <理由>
# 键不含行号（行号随无关改动漂移），也不含锚点（`#` 在本文件里是注释起始符，
# 键里带它会被截断，那类引用就永远无法登记）。
#
# 只登记**合法缺席**的引用：运行时生成且被 git 忽略的产物目录是典型一例。
# 不要用它掩盖真正写错的路径。
